# ArchIDE Releases

Binary release assets for ArchIDE (macOS, Windows, Linux installers).

This repository intentionally contains no source code — ArchIDE's source is
proprietary and lives in a private repository. This repo exists solely as a
public distribution point for signed/built installers and the auto-updater
feed consumed by `electron-updater`.

Download the latest release from the **Releases** tab on the right.
